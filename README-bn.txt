PetVerse ওয়েবসাইট: কীভাবে আপলোড করবেন
=========================================
1. cPanel > File Manager > public_html খুলুন।
2. petverse-site.zip আপলোড করুন, তারপর ডান ক্লিক করে Extract চাপুন।
3. index.php, index.html, shop-api.php, admin, data, img, inc ফোল্ডার public_html এর ভেতরে থাকতে হবে।
   (.htaccess ফাইলটাও লাগবে। File Manager > Settings > "Show Hidden Files" চালু করলে দেখা যাবে।)
4. ব্রাউজারে আপনার ডোমেইন খুলুন। সাইট চলে আসবে। PHP 8 লাগবে (cPanel এ সাধারণত থাকে)।

অ্যাডমিন প্যানেল (yourdomain.com/admin)
--------------------------------------
1. প্রথমবার খুললে নিজের নাম, Username আর Password (৮+ অক্ষর) দিন। এটাই মূল Super Admin।
2. Dashboard: আজকের ভিজিটর, এখন কতজন সাইটে, বিক্রি, অর্ডার, পেন্ডিং, ডেলিভারড, স্টক, ৭ দিনের চার্ট।
3. Orders: সাইট থেকে আসা সব অর্ডার। স্ট্যাটাস বদলান, ইনভয়েস প্রিন্ট, CSV export, ফোনের অর্ডার নিজে যোগ।
4. Courier Hub: Steadfast এর API key দিলে এক ক্লিকে পার্সেল পাঠানো আর ট্র্যাক।
5. Products: সাইজ, কালার, অনেক ছবি (কালার অনুযায়ী), AI দিয়ে ডেসক্রিপশন, Flash Sale / New / Best Seller / Featured।
6. Categories, Collections, Inventory, Reviews, Hero Banners, Homepage CMS (উপরের লেখা, Deal of the Day, About)।
7. Admin & Roles: ম্যানেজার বা স্টাফ অ্যাকাউন্ট বানান। স্টাফ শুধু অর্ডার/প্রোডাক্ট দেখে, টাকা-পয়সার সেটিং দেখে না।
8. Site Settings: দোকানের তথ্য, ডেলিভারি চার্জ, bKash/Nagad নাম্বার, Steadfast, SMS, Facebook Pixel + CAPI, Google SEO।
9. "Copy photos to server" বাটন (Products পেজে): অনলাইন থেকে নেওয়া ছবিগুলো আপনার সার্ভারে কপি করে। একবার চাপুন।

ইউজারনেম বা পাসওয়ার্ড ভুলে গেলে: cPanel > public_html এ reset-admin.txt নামে একটা খালি ফাইল আপলোড করুন, তারপর /admin খুলে নতুন ইউজারনেম আর পাসওয়ার্ড বানান।
সব অর্ডার, পাসওয়ার্ড আর API key থাকে data/private ফোল্ডারে। এটা বাইরে থেকে কেউ খুলতে পারে না। মাঝে মাঝে এই ফোল্ডারের ব্যাকআপ রাখুন।

প্রথমবার চালু করে যা করবেন
---------------------------
- Site Settings > General: ইমেইল, Facebook পেজ লিংক দিন (খালি থাকলে সাইটে দেখাবে না)।
- Payment: bKash / Nagad নাম্বার দিলে চেকআউটে অপশন আসবে।
- Steadfast, SMS, Pixel: key দিয়ে একটা টেস্ট অর্ডার দিয়ে দেখে নিন ঠিক চলছে কিনা।

দাম আর ছবি
-----------
দামগুলো অনলাইন দোকানের বাজারদর থেকে নেওয়া। আপনার দোকানের দাম অ্যাডমিন থেকে ঠিক করে নিন। দাম খালি রাখলে "Ask price on WhatsApp" দেখাবে।
কিছু ব্র্যান্ডের ছবি অনলাইনে পাওয়া যায়নি, সেগুলোতে ব্র্যান্ডের নাম দেখায়। নিজের ছবি তুলে অ্যাডমিন থেকে আপলোড করলে সবচেয়ে ভালো।
